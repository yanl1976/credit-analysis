# 合作方资信分析系统

面向集团及多级子公司的合作方资信评估平台。系统统一归集公开渠道数据与企业内部录入信息，按统一口径输出信用评分、风险预警与资信报告，为供应商/客户准入、分级管理与风险处置提供依据。

- 以客户（合作方）为主体，按统一社会信用代码归一，避免同一企业重复建档
- 支持集团—子公司多级组织，数据按归属组织隔离
- 评分过程可解释，每个扣分项都可追溯到具体记录

## 功能特性

### 概览看板
汇总客户总量、评分分布、风险等级构成、风险名单分布、近期预警与采集任务概况，快速掌握整体资信状况；
定期复审到期情况（逾期 / 临期 / 未排期）在顶部提示，可一键跳转到已筛选的客户列表。

### 客户管理
客户建档、检索与维护；列表直接展示信用评分、工商状态、准入状态与下次复审日期，支持单个/批量重算评分，
长列表按内容自适应显示。

- **准入状态（风险名单）**：正常 / 关注 / 重点监控 / 黑名单，列表可按状态筛选，有管理权限时可直接在列表内调整；黑名单与重点监控行高亮。
- **定期复审**：记录下次评估日期（评分或新建时按复审周期自动排期，可手工指定），列表按「已逾期 / 临期 / 未排期 / 已排期」筛选，逾期与临期日期标红提示。
- **导出**：客户清单可按当前筛选范围导出 CSV（UTF-8 BOM，Excel 直接打开不乱码）；资信报告可导出单客户报告（基本信息 + 扣分明细）。

### 资信报告
单个客户的完整资信视图，包含：

- 企业画像：工商登记信息、企业简介、风险概览、创新能力等
- 风险明细：司法（失信、被执行、裁判文书等）与合规（经营异常、行政处罚、税收违法等）记录
- 财务数据：报表科目与关键指标
- 评分明细：总分、等级、风险等级与逐项扣分原因，支持历史评分回看
- 报告中可直接切换上一条/下一条客户，保持当前检索范围

### 预警中心
按客户维度推送评分等级变化等风险事件，支持查看预警详情与跳转对应客户。

- **处置闭环**：预警状态分「未处理 / 处理中 / 已关闭」，处置时记录处理人、处理时间与处置备注；
  列表可按处置状态筛选，支持撤销处置（置回未处理并清空处理信息）。
- **统计**：显示待处理总量（不限时间窗，未关闭即持续催办）、近 N 天已关闭数与状态分布。

### 数据采集
内置多个外部数据渠道，按已配置的凭据自动启用，未配置的渠道自动跳过：

- 工商与风险数据渠道（开放平台接口）
- 企业画像与风险明细服务
- 上市公司财务数据
- 联网检索与 AI 辅助档案填充（可选）

采集结果与原始报文留档，便于复核与重新解析。

### 系统设置
集中管理系统名称、评分与预警开关、列表分页、定期复审周期与临期提醒天数、数据渠道凭据与调用预算等；
组织、人员与角色权限由集团管理员维护。

## 角色与权限

| 角色 | 数据范围 | 主要能力 |
| --- | --- | --- |
| 集团管理员 | 全部组织 | 组织/人员/角色管理、系统设置、全部客户数据 |
| 子公司管理员 | 本组织及下级 | 本组织客户建档、采集与评分 |
| 普通用户 | 本组织 | 查看客户资信报告与预警 |

菜单与操作按钮均按权限动态显示。

## 快速开始

### 环境要求

- Node.js 18 及以上
- MySQL 8
- 现代浏览器（Chrome / Edge / Firefox 最新版）

### 后端

```bash
npm install
cp .env.example .env      # Windows: copy .env.example .env
# 按 .env 注释填写数据库连接与外部渠道凭据
npm run migrate           # 初始化数据库结构
npm run seed              # 预置组织、角色与管理员账号
npm start                 # 默认 http://localhost:3000
```

### 前端

```bash
cd frontend
npm install
npm run dev               # 默认 http://localhost:5173，已代理后端接口
```

生产环境执行 `npm run build` 生成静态资源，交给前端托管服务部署。

### 默认账号

首次初始化会创建管理员账号 `admin / admin123`，也可通过环境变量 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 指定。**正式上线前请务必修改密码。**

### 演示数据

如需快速体验，可执行 `npm run seed:demo` 写入演示客户与评分数据。

## 目录结构

```
├─ src/            后端服务（接口、业务服务、数据访问、初始化脚本）
├─ frontend/       前端工程（页面、组件、状态与接口封装）
├─ config/         渠道与运行配置
├─ docs/           技术方案与开发规范
└─ data/           运行期数据与缓存（不纳入版本管理）
```

## 配置说明

所有运行参数集中在根目录 `.env`，模板见 `.env.example`。敏感信息（数据库密码、渠道密钥、访问令牌）只写在 `.env` 中，`.env` 已被版本管理忽略，请勿提交。

外部渠道均按“配置即启用”处理：缺少凭据的渠道会自动跳过并在界面提示，不影响其它功能。
